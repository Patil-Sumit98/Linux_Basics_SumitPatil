# Linux Basics Command-Line Assignment

A practical lab assignment demonstrating essential Linux command-line operations, shell scripting basics, system administration commands, and file management techniques.

---

## 📌 Objectives

- Practice file and directory management (creation, moving, renaming).
- Inspect and monitor file contents using viewing utilities.
- Perform text processing and pattern matching using `grep`.
- Manage archiving, file permissions, and environment variables.
